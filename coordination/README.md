# Обмен заданиями и проверками между чатами

GitHub — общий источник кода, заданий и доказательств. Чаты не обмениваются сообщениями напрямую и не запускаются автоматически.

## Цикл
1. Разработчик фиксирует сборку коммитом и создаёт задание по TASK-TEMPLATE.md.
2. Пользователь даёт другому чату ссылку на репозиторий, ветку задания, путь задания и роль.
3. Проверяющий читает AGENTS.md, получает точный SHA, выполняет проверки и открывает PR с отчётом.
4. Пользователь пишет основному чату «собери проверки из GitHub». Основной чат получает PR самостоятельно; перенос текста не нужен.
5. Разработчик анализирует доказательства, исправляет ошибки и назначает повторные проверки на новом SHA.

## Разделение ролей
- physics: формулы, размерности, знаки, аналитические задачи, энергия.
- numerical: временная и пространственная сходимость, контакты, rollback, расчётные сценарии.
- regression-ui: регрессия, браузер, синхронность визуализации.

Отчёты разных ролей сохраняются в разных каталогах. Каждый PR содержит только свою проверку.
В main сливает основной разработчик после анализа. Шаблоны не означают включённую защиту веток.

## Доступ
Каждому чату нужен доступ к GitHub и этому репозиторию. Если запись недоступна, он должен явно сообщить BLOCKED.
Не помещайте токены и пароли в сообщения, код или отчёты.
